      자동 검사 상세

      앱 개인정보 보호 리포트 분석

      아이폰이 직접 기록한 '어떤 앱이 언제 위치에 접근했고, 어떤 사이트와 통신했는지'를 분석해요. 파일은 이 화면 안에서만 읽고, 어디에도 올리지 않아요.

      리포트 파일 받는 방법
      1. 설정 → 개인정보 보호 및 보안을 눌러요.
      2. 맨 아래까지 내려 앱 개인정보 보호 리포트를 눌러요.
      3. 꺼져 있다면 앱 개인정보 보호 리포트 켜기를 눌러요. 켠 시점부터 기록이 쌓여요. 평일 2~3일 이상 지나고 받으면 분석이 정확해요.
      4. 같은 화면 맨 아래 앱 활동 저장 → "파일"에 저장을 눌러요. (App_Privacy_Report_….ndjson 파일이 생겨요)
      5. 이 화면에서 리포트 파일 선택을 눌러 방금 저장한 파일을 골라요.

      리포트는 최근 7일치만 보관돼요. 매주 한 번씩 저장해 두면 기간을 비교할 수 있어요.

      회사 와이파이로 본 나의 하루

      회사 장비에 남은 기록만으로 하루를 재구성하면 이렇게 보여요. 날짜를 골라 보세요.

        위치 접근 분석

        출퇴근 시간대출퇴근 체크로 보이는 기록이에요. 회사가 알아요. 체크 순간의 위치가 근태 기록에 남아요.
        근무시간·점심앱을 열었을 때의 기록이에요. 위치가 회사 서버로 전송됐는지는 확인할 수 없어요.
        근무 외퇴근 후·휴일 기록이에요. 집 근처 위치일 수 있어서 가장 민감해요. 위치 권한을 '다음번에 묻기'로 바꾸면 막을 수 있어요.

        시간대별 위치 접근

        칸을 누르면 그 시간에 위치에 접근한 앱이 보여요.

        앱별 위치 접근

        업무용 앱이 아닌 앱의 위치 접근은 폰 안에서 일어난 일이라 회사는 알 수 없어요.

        회사 관리자 화면 미리보기

        회사 방화벽·공유기 관리 화면에 내 기록이 어떤 모습으로 남는지 재구성한 예시 화면이에요. 특정 업체 제품 화면이 아니에요. 네트워크 진단 결과와 기록 분석 데이터를 함께 반영해요.

        관리자가 이 화면으로 알 수 있는 것

          트래픽 로그 · 예시

          '내용' 칸이 암호화로 표시되면 관리자는 접속한 사이트 이름까지만 볼 수 있어요. 메시지나 검색어 같은 내용은 볼 수 없어요.

          이 진단은 회사가 기록을 볼 수 있는 구조인지를 판단해요. 회사 서버에 실제로 무엇이 저장되는지는 알 수 없어요.

          네트워크 검사에 쓰는 외부 서비스: Cloudflare(연결 정보), tls.peet.ws(TLS 지문), httpbin.org(요청 헤더), ipwho.is(통신사 정보), Google·Cloudflare STUN(WebRTC). 이 서비스들은 일반 웹 요청처럼 접속 IP를 볼 수 있어요. 리포트 파일은 외부로 보내지 않아요.

          판정은 휴리스틱이라 오탐이 있을 수 있어요.
